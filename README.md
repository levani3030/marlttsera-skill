# marlttsera — ქართული მართლწერის სკილი Claude Code-ისთვის

სკილი, რომელიც Claude-ს ქართულად გამართულად წერას ასწავლის: სწორი ბრუნვები და შეთანხმება, მართლწერა, რთული სიტყვების დაწერილობა, პუნქტუაცია და ბუნებრივი, არანათარგმნი სტილი. წესები ამოკრებილია ქართული სალიტერატურო ენის ოფიციალური ნორმებიდან.

## რას აკეთებს

- **წერისას** — Claude ნებისმიერი ქართული ტექსტის (პასუხი ჩატში, დოკუმენტაცია, ინტერფეისის სტრიქონები, წერილი, commit) დაწერამდე ტვირთავს სკილს, წერს მისი წესებით და გაგზავნამდე ტექსტს თვითშემოწმების სიით გადის.
- **კორექტურა** — „შეამოწმე / გაასწორე ეს ტექსტი“: შეცდომები ჯგუფდება სიმძიმით (შეცდომა, პუნქტუაცია, სტილი, სადავო) და თითოეულს ახლავს წესი.
- **წესის ახსნა** — „როგორ იწერება…?“, „რატომ არის ასე?“: პასუხი წესით, მაგალითებითა და წყაროთი.
- **სიტყვის ძიება** — `scripts/lookup.mjs`: ერთად, დეფისით თუ ცალკე; ნორმით უარყოფილი ფორმა და მისი სწორი შესატყვისი.
- **მექანიკური შემმოწმებელი** — `scripts/lint.mjs`: 1600-ამდე უარყოფილი ფორმა და წესი (ბრჭყალები, ტირე, შერეული დამწერლობა, აშკარა მძიმეები, ციფრებზე დართული ნიშნები).
- **ავტომატური ჩართვა** — ორი hook: ქართული ტექსტის შემცველ მოთხოვნაზე Claude-ს სკილი ახსენდება; ფაილში ჩაწერილი ქართული ტექსტი ავტომატურად მოწმდება და შენიშვნები Claude-ს უბრუნდება.

## ინსტალაცია

```
git clone https://github.com/<მომხმარებელი>/marlttsera.git
cd marlttsera
python install.py              # სკილი + hook-ები + მითითება CLAUDE.md-ში
python install.py --no-hooks   # hook-ების გარეშე
python install.py --uninstall  # წაშლა
```

იგივე Node.js-ით, თუ Python არ გაქვს:

```
node install.mjs
node install.mjs --no-hooks
node install.mjs --uninstall
```

ორივე ინსტალატორი ერთნაირად მუშაობს და ერთმანეთის დაყენებულ ასლს ცნობს: ერთით დაყენებულს მეორით წაშლი ან განაახლებ.

ინსტალატორი:
1. აკოპირებს `marlttsera/` საქაღალდეს `~/.claude/skills/marlttsera`-ში;
2. `~/.claude/settings.json`-ში ამატებს ორ hook-ს (არსებულს არ ეხება; ქმნის სარეზერვო ასლს `settings.json.marlttsera-backup`);
3. `~/.claude/CLAUDE.md`-ში ამატებს მითითებას, რომ ქართული ტექსტის წერამდე სკილი ჩაიტვირთოს.

შემმოწმებელსა და hook-ებს Node.js 18+ სჭირდება; `install.py`-ს — დამატებით Python 3.8+. სკილში ცვლილების შეტანის შემდეგ ინსტალატორი ხელახლა გაუშვი.

## გამოყენება

- ქართულად მისწერე Claude-ს — სკილი თავად ჩაირთვება.
- `/marlttsera შეამოწმე docs/guide.md` — ფაილის კორექტურა.
- `/marlttsera როგორ იწერება: ვებ-გვერდი თუ ვებგვერდი?` — წესის ახსნა.
- ხელით:
  ```
  node ~/.claude/skills/marlttsera/scripts/lint.mjs ფაილი.md
  node ~/.claude/skills/marlttsera/scripts/lint.mjs --text "ვფიქრობ რომ ეს სპეციფიური შემთხვევაა"
  node ~/.claude/skills/marlttsera/scripts/lookup.mjs ვებ-გვერდი ონლაინ
  ```

## წყაროები

- „თანამედროვე ქართული სალიტერატურო ენის ნორმები, პირველი კრებული“ (1986);
- „ოფიციალურ-საქმიანი დოკუმენტების მართლწერის გზამკვლევი“ (თ. ბურჭულაძე, 2024);
- „თანამედროვე ქართული სალიტერატურო ენის ნორმები – კომპოზიცია“ (თსუ არნ. ჩიქობავას სახ. ენათმეცნიერების ინსტიტუტი, 2025);
- Microsoft Georgian Style Guide;
- სახელმწიფო ენის დეპარტამენტის ნორმები და შესწორებათა ბაზა (enadep.gov.ge), მთავრობის №394 (2020) და №362 (2025) დადგენილებები;
- პუნქტუაციის სახელმძღვანელოები (ბასილაია 1966, ზარდალიშვილი 1995, არაბული 2008, ვარდიაშვილი–ზვიადაძე 2009), Unicode CLDR, Microsoft / Mozilla / GNOME / Android-ის ქართული ლოკალიზაციები.

დაწვრილებით — `marlttsera/references/sources.md`.

## მოვლა

- **ახალი უარყოფილი ფორმის დამატება:** ჩაამატე სტრიქონი `data/wordlist.tsv`-ში (`kind`, `pattern`, `suggestion`, `level`, `note` — TAB-ით გამოყოფილი). დაამატე მხოლოდ ისეთი ფორმა, რომელიც სხვა სწორ სიტყვას არ ემთხვევა; ყოველი ცრუ განგაში შემმოწმებლისადმი ნდობას ამცირებს.
- **ცრუ განგაში:** წაშალე ან `warn`-ად გადააკეთე შესაბამისი სტრიქონი `wordlist.tsv`-ში.
- **წესის შეცვლა:** ჩაასწორე შესაბამისი ფაილი `references/`-ში; თუ წესი ხშირ შეცდომას ეხება — `SKILL.md`-ის ბირთვიც.
- **ახალი ნორმები:** 2023–2025 წლებში ექსპერტთა კომისიამ განიხილა ოცდაათამდე ნორმა, რომელთა ტექსტები ჯერ გამოუქვეყნებელია (ჰ-/ს- პრეფიქსები, ზმნისწინები, „ჩემ მიერ“ ტიპის შესიტყვებები და სხვ.). გამოქვეყნების შემდეგ `references/verbs.md`, `syntax.md` და `sources.md` გადასამოწმებელია.

## შეზღუდვები

- შემმოწმებელი მექანიკურია: ბრუნვის, შეთანხმებისა და სტილის შეცდომებს ვერ ხედავს — მათ Claude ამოწმებს სკილის წესებით. სრული გარანტია არც ერთს არ აქვს; მნიშვნელოვანი ტექსტი ადამიანმაც უნდა წაიკითხოს.
- 1986 წლის კრებული სკანირებული ასლის ტექსტური შრიდანაა ამოღებული; საეჭვო ადგილები გამოტოვებულია, მაგრამ ცალკეულ მაგალითში უზუსტობა გამორიცხული არ არის.
- სადაც ნორმა არ არსებობს ან წყაროები არ თანხმდება (პუნქტუაციის დეტალები, ტიპოგრაფიკა, IT-ტერმინები), სკილი ასახელებს გავრცელებულ პრაქტიკას და ამას ღიად აღნიშნავს.
