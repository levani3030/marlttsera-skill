# პუნქტუაცია

პუნქტუაციის ოფიციალურად დამტკიცებული ახალი ნორმა არ არსებობს; წესები ეყრდნობა სახელმძღვანელოებს, რომლებიც ძირითადად ერთმანეთს ემთხვევა: ნ. ბასილაია, „სასვენი ნიშნების ხმარების წესები ქართულში“ (1966) [ბ]; ს. ზარდალიშვილი, „ქართული მართლწერის 120 წესი / პუნქტუაცია“ (1995) [ზ]; ა. არაბული, „ქართული მეტყველების კულტურა“ (2008) [ა]; მ. ვარდიაშვილი, მ. ზვიადაძე, „სასვენი ნიშნების ხმარება ქართულ წინადადებაში“ (2009) [ვზ]; „ოფიციალურ-საქმიანი დოკუმენტების მართლწერის გზამკვლევი“ (2024) [გზ]. სადაც წყაროები არ თანხმდება, ეს მითითებულია.

## სარჩევი
1. მძიმე: სად იწერება
2. მძიმე: სად არ იწერება (ზედმეტი მძიმე)
3. ჩართული სიტყვები
4. ტირე და დეფისი
5. ორწერტილი და წერტილ-მძიმე
6. ბრჭყალები
7. პირდაპირი ნათქვამი, დიალოგი, სხვათა სიტყვა
8. მრავალწერტილი, ფრჩხილები
9. სათაურები და ჩამონათვალი
10. ნიშნების შეთავსება

---

## 1. მძიმე: სად იწერება

**მთავარი წესი:** დამოკიდებული წინადადება მთავრისგან მძიმით გამოიყოფა — თავში ან ბოლოში ერთი მძიმით, შუაში ორივე მხრიდან. [ვზ, ზ, ბ]

- ✓ ბინდდებოდა, როცა შინ დავბრუნდით. ✓ ქალი, რომელიც ჩემ წინ დგას, ჩვენი მეზობელია.
- **„რომ“-ის წინ** მძიმე იწერება, როცა „რომ“ დამოკიდებულ წინადადებას **იწყებს**: ✓ მინდა, რომ წამოხვიდე. ✓ ვფიქრობ, რომ ასე სჯობს. ✗ მინდა რომ წამოხვიდე.
- **„რომ“ წინადადების შიგნით** — მის წინ მძიმე არ იწერება, მძიმე იწერება მთელი დამოკიდებული წინადადების ბოლოს: ✓ სვანეთში რომ ჩავედით, ციოდა. ✗ სვანეთში, რომ ჩავედით, ციოდა. ასევე: ✓ წიგნს თუ წაიკითხავ, ბევრს გაიგებ.
- **გამოტოვებული „რომ“:** მძიმე მაინც იწერება: ✓ კახამ გადაწყვიტა, ქორწილი არ გადაეხადა. ✓ გთხოვთ, შეამოწმოთ. ✓ გსურთ, განაგრძოთ? (მოკლე წინადადებაში მძიმის გამოტოვებას [ბ] უშვებს: „გთხოვთ მობრძანდეთ“; რეკომენდებულია მძიმე.)
- **მაქვემდებარებელი კავშირებისა და მიმართებითი სიტყვების წინ**, როცა დამოკიდებულ წინადადებას იწყებენ: რომელიც (რომლის, რომელსაც, რომლებიც…), რადგან, რადგანაც, ვინაიდან, რაკი, რათა, როცა, როდესაც, სანამ, ვიდრე, სადაც, ვინც, რაც, როგორც, თუ, თუმცა, თორემ.
- **მაპირისპირებელი კავშირების წინ:** მაგრამ, ხოლო, თუმცა, ოღონდ, არამედ: ✓ ციოდა, მაგრამ მაინც წავიდნენ.
- **„კი“:** მძიმე იწერება წინადადებათა საზღვარზე და არა „კი“-ს წინ ან შემდეგ: ✓ ქალები წამოიშალნენ, კაცებმა კი სმა განაგრძეს. „ხოლო“ და „კი“ ერთად არ იხმარება: ✗ მე წავედი, ხოლო ის კი დარჩა. [ზ]
- **შედგენილი კავშირები** — მძიმე მისათითებელ სიტყვასა და კავშირს შორის: იმიტომ, რომ; იმის გამო, რომ; იმისთვის, რომ; ისე, რომ; მას შემდეგ, რაც; მიუხედავად იმისა, რომ; იმ დროს, როცა. ✓ არ მოვიდა იმიტომ, რომ ავად იყო. ✓ მას შემდეგ, რაც წავიდა, აღარ მინახავს. „ასე რომ“ — შიდა მძიმის გარეშე. [ბ, ა]
- **ორი კავშირის შეხვედრა** (სხვადასხვა წინადადებისა) — მათ შორის მძიმე: ✓ ესმოდა, რომ, თუ გაიგებდა, საქმე გართულდებოდა. ✓ …, მაგრამ, როცა ხმა მიწყნარდა, გამოვიდა. [ბ] (პრაქტიკაში „რომ თუ“ ხშირად უმძიმოდაც იწერება.)
- **ერთგვარი წევრები** უკავშიროდ — მძიმით: ✓ იყიდა წიგნები, რვეულები და კალმები.
- **განმეორებული კავშირები** (ან… ან, ხან… ხან, არც… არც, თუ… თუ) — მძიმე ყოველი მომდევნოს წინ: ✓ ან ივლისში წავალთ, ან აგვისტოში. ✓ არც მეტი, არც ნაკლები.
- **წყვილი კავშირები** (როგორც… ისე; არამარტო… არამედ; არა… არამედ) — მძიმე მეორე ნაწილის წინ: ✓ როგორც შიგნით, ისე გარეთ.
- **მიმართვა** — ყოველთვის გამოიყოფა: ✓ გამარჯობა, ნინო, როგორ ხარ? ✓ ძვირფასო მომხმარებელო, …
- **დანართი** — მძიმეებით: ✓ ნინო, ჩემი კლასელი, ექიმია. **ანუ, ესე იგი (ე. ი.)** — მძიმე მათ წინ: ✓ სამცხე, ანუ ახლანდელი ახალციხის მხარე. (ორსიტყვიან სინონიმურ წყვილში „ანუ“-ს წინა მძიმე პრაქტიკაში ხშირად აკლია.)
- **განკერძოებული განსაზღვრება** (საზღვრულის შემდეგ) — მძიმით: ✓ საღამო იყო, თბილი და წყნარი. საზღვრულის წინ მდგომი მიმღეობური ჯგუფი **არ** გამოიყოფა: ✓ გუშინ მიღებული წერილი მაგიდაზე დევს.
- **შედარება** „ვიდრე“, „როგორც“, „თითქოს“ კავშირებით — მძიმე: ✓ უფრო მეტი მოკრიფა, ვიდრე სხვებმა. „როგორც“ როლის მნიშვნელობით (= -ად) — უმძიმოდ: ✓ ვიცნობ როგორც კარგ სპეციალისტს. -ვით თანდებულიანი სიტყვა არ გამოიყოფა.
- **დიახ, არა, კი, ჰო** და შორისდებული — მძიმით: ✓ დიახ, მზადაა.
- **თანამდებობა + „ქალბატონ/ბატონ“ + სახელი** მიცემითსა და ნათესაობითში — მძიმით: ✓ მოსამართლეს, ქალბატონ თამარ ახალაიას. თანამდებობა + სახელი და გვარი მოთხრობითში — უმძიმოდ: ✓ კანდიდატმა მზია ნიაურმა განაცხადა. (ბრუნება იხ. nouns.md.) [გზ, გვ. 137–138]

## 2. მძიმე: სად არ იწერება

ზედმეტი მძიმე უფრო ხშირი შეცდომაა, ვიდრე ნაკლული. [გზ, გვ. 130]

- **„და“-ს წინ** (ერთგვარ წევრებსა და თანწყობილ წინადადებებს შორის): ✓ შედით სისტემაში, გახსენით პარამეტრები და შეარჩიეთ კონფიგურაცია. ✗ …, და შეარჩიეთ. გამონაკლისი — როცა „და“-ს წინ დამოკიდებული წინადადება ან ჩართული იხურება, ან „და“-ს შემდეგ ჩართული იწყება: ✓ მოვიდა კაცი, რომელსაც ველოდით, და საუბარი დაიწყო. ✓ …და, მეორე მხრივ, …
- **ერთხელ ნახმარი „ან“, „თუ“ ერთგვარ წევრებს შორის:** ✓ ივლისში ან აგვისტოში. ✓ დიდსა თუ პატარას. (წინადადებებს შორის „ან“-ის წინ მძიმე იწერება: ✓ გამოიყენეთ ნაგულისხმევი კონფიგურაცია, ან შეარჩიეთ სასურველი პარამეტრები.)
- **კავშირის შემდეგ:** „მაგრამ“, „თუმცა“, „ხოლო“ სიტყვების შემდეგ მძიმე არ იწერება, თუ ჩართული ან სხვა კავშირი არ მოსდევს: ✗ თუმცა, საჩივრების უმეტესობა… ✓ თუმცა, რა თქმა უნდა, ასეთ შედეგს არ ველოდი. [გზ, გვ. 130]
- **ნაწილაკებისა და თანდებულების შემდეგ:** კი, გამო, მიერ, თურმე, თუნდაც, შემდეგ, თითქოს, თითქმის, სწორედ, მაინც, ასევე, აგრეთვე. ✗ ამის გამო, სასურველია… ✗ კომიტეტს, ასევე, შეუძლია… ✗ კომისიის მიერ, კანდიდატები შეფასდნენ. [გზ, გვ. 131–132]
- **მხოლოდ პაუზის გამო:** შემთხვევაში, საშუალებით, ფარგლებში, მიზნით, საფუძველზე, მდგომარეობით, თანახმად, შესაბამისად, გათვალისწინებით, პასუხად, აქვე — ამ სიტყვებზე დაბოლოებული გარემოების შემდეგ მძიმე არ იწერება, თუ კავშირი ან ჩართული არ მოსდევს: ✗ რეფორმის ფარგლებში, პროცედურა გამარტივდა. ✓ რეფორმის ფარგლებში პროცედურა გამარტივდა. [გზ, გვ. 133–135] (პრაქტიკაში, თვით გზამკვლევშიც, ვრცელი შესავალი გარემოების შემდეგ მძიმე გვხვდება; მოკლე გარემოებასთან ნუ დასვამ.)
- **თარიღის შემდეგ:** ✗ 2021 წელს, კმაყოფილების დონე 88%-ია. ✓ 2021 წელს კმაყოფილების დონე 88%-ია. [გზ, გვ. 136]
- **სახელზმნის წინ, როცა „რომ“ არც არის და არც იგულისხმება:** ✗ ჩვენი მიზანია, სერვისების მიწოდება. ✓ ჩვენი მიზანია სერვისების მიწოდება. (შდრ. ✓ ჩვენი მიზანია, მივაწოდოთ სერვისები.) [გზ, გვ. 132]
- **ქვემდებარესა და შემასმენელს შორის**; საზღვრულის წინ მდგომ განსაზღვრებასთან; არაერთგვარ განსაზღვრებებს შორის (✓ სამი ოქროს მედალი; ჭრელი ჩითის კაბა).

## 3. ჩართული სიტყვები

ჩართული წინადადების წევრი არ არის (კითხვა არ დაესმის); თავში ან ბოლოში ერთი მძიმით გამოიყოფა, შუაში — ორივე მხრიდან. [ვზ, ზ; გზ, გვ. 139–143]

**ყოველთვის გამოიყოფა:** რა თქმა უნდა, რასაკვირველია, უეჭველად, ბოლოს და ბოლოს; მგონი, როგორც ჩანს, თუ არ ვცდები; სამწუხაროდ, საბედნიეროდ; ჩემი აზრით, როგორც ამბობენ, ავტორის ცნობით; როგორც წესი, როგორც ცნობილია; ჯერ ერთი, მეორეც, ერთი მხრივ, მეორე მხრივ, ერთი სიტყვით, ამრიგად, მაშასადამე, დასასრულ, სხვათა შორის, მაგალითად, კერძოდ, უფრო სწორად, ასე ვთქვათ, ყოველ შემთხვევაში, მით უმეტეს, უპირველეს ყოვლისა; გთხოვთ (თხოვნის ფორმულად).

- ✗ თბილისი - დედაქალაქი (ჰარებიანი დეფისი ტირის ნაცვლად) → ✓ თბილისი – დედაქალაქი. ✗ დედ – მამა → ✓ დედ-მამა.

**დეფისი იწერება:** კომპოზიტებში (იხ. compounds.md); ციფრზე, ლათინურ სიტყვაზე, სიმბოლოზე ან ინიციალურ აბრევიატურაზე ბრუნვის ნიშნის/თანდებულის დართვისას (5-ის, მე-15, 20%-ით, Windows-ის, %s-ის, აშშ-ში, III-მ); -მეთქი, -თქო ნაწილაკებთან; რიცხვთა შუალედში უჰაროდ (XIX-XX სს., 22-26 სექტემბერს, 50-100 სიტყვა, 2019-2020 წლები; ლოკალიზაციის მონაცემებში (CLDR) შუალედს მოკლე ტირე აღნიშნავს: 22–26 — ორივე გვხვდება, ტექსტში ერთგვაროვნება დაიცავი).

**ტირე იწერება:**
- გამოტოვებული „არის“-ის ადგილას: ✓ რუსთავი – მრეწველობის ცენტრი. (ან: რუსთავი მრეწველობის ცენტრია. ✗ რუსთავი, მრეწველობის ცენტრი.)

- **სხვათა სიტყვის ნაწილაკები:** -მეთქი (ჩემი ნათქვამი): ვუთხარი, მოვალ-მეთქი; -თქო (სხვას ვაბარებ): უთხარი, მოვიდა-თქო; -ო (მისი / შენი / ჩვენი ნათქვამი): მოვალო, თქვა. **-ო ერწყმის, -მეთქი და -თქო დეფისით იწერება.** ნაწილაკი ჩვეულებრივ ბოლო სიტყვას ერთვის. ✗ მოვიდა-ო, ✗ მოვიდამეთქი, ✗ მოვიდა-თქვა.
- არაპირდაპირი კითხვის ბოლოს კითხვის ნიშანი არ იწერება: ✓ არ ვიცი, ვინ მოვიდა. ✗ არ ვიცი, ვინ მოვიდა?

## 8. მრავალწერტილი, ფრჩხილები

- მრავალწერტილი სამი წერტილია (… ან ...), წინა სიტყვას უჰაროდ ებმის: ✓ იგზავნება… ნიშნების გაორმაგება („!!“, „???“) მიღებული არ არის.
- ციტატაში გამოტოვებული ადგილი: […]; ავტორის ჩანართი — კვადრატულ ფრჩხილებში.
- ფრჩხილის შიგნით კიდეებთან ჰარი არ არის, გამხსნელის წინ — არის: ✓ 4 გვერდი (1200 სიტყვა).
- წერტილი, მძიმე, ორწერტილი, ტირე — მხოლოდ დამხურავი ფრჩხილის **შემდეგ**: ✓ …მეგობრებიც მიდიან (მხოლოდ ბიჭებს დავასახელებ): გიორგი, ნიკა. ფრჩხილებიანი ჩანართი წინადადების შიგნით რჩება; წერტილი ფრჩხილის წინ არ იწერება.
- ციტატა + (წყარო): წერტილი ფრჩხილის შემდეგ.

## 9. სათაურები და ჩამონათვალი

- **სათაურის ბოლოს წერტილი არ იწერება** (კითხვის ნიშანი — შეიძლება). ✓ შესავალი ✗ შესავალი.
- ღილაკის, მენიუს, ცხრილის თავსართის ტექსტი — ბოლო ნიშნის გარეშე.
- **ჩამონათვალი:**
  - პუნქტები სრული წინადადებებია → თითოეული წერტილით მთავრდება.
  - პუნქტები ერთი წინადადების ნაწილებია → შესავალი ფრაზის შემდეგ ორწერტილი, პუნქტებს შორის წერტილ-მძიმე, ბოლოს წერტილი.
  - სულ მოკლე (ერთ-ორსიტყვიანი) პუნქტები ცხრილსა და ინტერფეისში — ნიშნის გარეშე.
  - ერთ სიაში ერთი სქემა.
- ნუმერაცია: „1.“, „ა)“, „1)“. ქართული ასოებით: ა, ბ, გ, დ, ე, ვ, ზ, თ, ი, კ, ლ, მ, ნ, ო, პ, ჟ, რ, ს, ტ, უ, ფ, ქ, ღ, ყ, შ, ჩ, ც, ძ, წ, ჭ, ხ, ჯ, ჰ.
- ქართულში დიდი ასოები არ არის, ამიტომ პუნქტის „დიდი ასოთი დაწყება“ არ არსებობს; ინგლისური სიტყვების რეგისტრი უცვლელად რჩება.
