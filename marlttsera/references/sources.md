## სადაც წყაროები ერთმანეთს არ ემთხვევა ან ნორმა ჯერ გამოუქვეყნებელია

ასეთ ადგილებში სკილი ასახელებს ნორმით უპირატეს ფორმას, მაგრამ მეორეს შეცდომად არ აცხადებს.

- **ჩემ მიერ / ჩემს მიერ.** ნორმა (1986), გზამკვლევი (2024) და დეპარტამენტის ბაზა: „ჩემ მიერ“. პრაქტიკაში „ჩემს მიერ“ ფართოდაა გავრცელებული; ექსპერტთა კომისიის 2024 წლის ნორმის ტექსტი გამოუქვეყნებელია.
- **უნახავს / უნახია.** 2022 წლის ნორმა -ია ფორმას დასაშვებად ცნობს; დეპარტამენტის ბაზა მას ჯერ კიდევ „არასწორად“ ასახელებს.
- **კორპორაციული / კორპორატიული; ლაკონიური / ლაკონური; ტექსტობრივი / ტექსტუალური; ეფექტიანი / ეფექტური.** ბაზა პირველს ასახელებს, პრაქტიკაში მეორეც გაბატონებულია; ნორმის ტექსტი გამოუქვეყნებელია.
- **კვდებიან / იხოცებიან.** მკაცრი ნორმით მრავლობითში ფუძე იცვლება; „კვდებიან“ პრაქტიკაში ჩვეულებრივია.
- **ორმაგი უარყოფა** (არავინ არ მოსულა / არავინ მოსულა): განსაზღვრულ შემთხვევებში სავალდებულოა (არცერთი არ…), დანარჩენში ორივე მართებულია.
- **„ალბათ“ მძიმით თუ უმძიმოდ; „მაგრამ, / თუმცა,“-ს შემდეგ მძიმე; ჩადგმული ბრჭყალები; დამხურავი ბრჭყალის გლიფი (“ თუ ”).**
- **ა. შ. / ა.შ.; 5% / 5 %; კგ / კგ.; ათწილადის მძიმე თუ წერტილი; რიცხვთა შუალედში დეფისი თუ ტირე.**
- **IT-ტერმინები:** copy, edit, install, release, app, cookie, desktop და სხვ. — იხ. localization.md §7.
- 2023–2025 წლებში ექსპერტთა კომისიამ განიხილა ოცდაათამდე ნორმა (ჰ-/ს- პრეფიქსები, ზმნისწინები, III სერიის ფორმები, „ოთარიმ / ოთარმა“, -ურ/-ულ ნასესხებ სიტყვებში, სხვათა სიტყვის ნაწილაკები), რომელთა ტექსტები მთავრობის მიერ დამტკიცებამდე არ ქვეყნდება. მათი გამოქვეყნების შემდეგ სკილის შესაბამისი ნაწილები გადასამოწმებელია.

## მონაცემთა ფაილები

- `data/compounds.txt` — „კომპოზიტთა მცირე ლექსიკონი“ (კომპოზიცია, 2025), დაახლოებით 4000 სტატია.
- `data/index_1986.txt` — 1986 წლის კრებულის ორთოგრაფიული საძიებელი (სკანირებული წიგნის OCR-იდან აღდგენილი; საეჭვო სტატიები ამოღებულია). მოძველებული სტატიები (იხ. ზემოთ ცხრილი) შესაძლოა შემორჩენილი იყოს — ახალ ნორმას ენიჭება უპირატესობა.
- `data/wordlist.tsv` — შემმოწმებლის სია: ნორმით უარყოფილი ფორმა → სწორი ფორმა. შედგენილია ზემოთ ჩამოთვლილი წყაროებიდან; შეტანილია მხოლოდ ისეთი ფორმები, რომლებიც სხვა სწორ სიტყვას არ ემთხვევა.

## შეზღუდვები

- 1986 წლის კრებული სკანირებული ასლის ტექსტური შრიდანაა ამოღებული; აშკარა OCR-შეცდომები გასწორებულია, საეჭვო ადგილები — გამოტოვებული. ცალკეულ მაგალითში უზუსტობა გამორიცხული არ არის.
- სკილი ვერ ცვლის ორთოგრაფიულ ლექსიკონს: ცალკეული სიტყვის მართლწერის საბოლოო წყაროა „ქართული ენის ორთოგრაფიული ლექსიკონი“ და ენის დეპარტამენტის რესურსები (enadep.gov.ge, ena.ge).
