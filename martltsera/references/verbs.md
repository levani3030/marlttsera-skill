## I პირის ვ- და პირის ნიშანთა თავმოყრა

- I პირის ვ- არ იკარგება უ-, ო-, ვ-ს წინ: ვუთხარი, ვუგზავნი, ვუკავშირებ, ვოცნებობ, ვვარაუდობ, ვვარჯიშობ, შევვარდი. ✗ უთხარი (მე), ვარაუდობ (მე). [ნ86, გვ. 32–36; ენადეპ]
- ორი ერთნაირი თანხმოვანი იწერება: მმართებს, მმატებს; გგზავნი, გგონია; გვგვრის.
- „ყოფა“-ზმნიან რთულ ზმნებში პირის ნიშანი „ყოფ“-ს ერთვის: უზრუნველვყოფ, უარვყოფ, ცხადვყოფ, ნათელვყოფ, სრულვყოფ, შეურაცხვყოფ. ✗ ვუზრუნველყოფ, ვუარყოფ. მაგრამ: ვხელმძღვანელობ, ვშუამდგომლობ, ვავადმყოფობ.
- თანაუგრძნობს, თანამიგრძნობს (✗ უთანაგრძნობს).
- მე მას მივწერე / მე შენ მოგწერე / მან მე მომწერა: I და II პირის ადრესატთან „მო-“ ზმნისწინი, III პირისასთან — „მი-“ (✗ მე შენ მიგწერე; ✗ მე მას მოვწერე).

## აღწერითი ვნებითი („იქნა“)

- „იქნა“-ს წინ მდგომი მიმღეობა ფუძის სახითაა: დადგენილ იქნა, მიღებულ იქნა, შემუშავებულ იქნა. შებრუნებით — სახელობითში: იქნა მიღებული. ✗ მიღებული იქნა. [გზ, გვ. 60]
- კავშირებითში **იქნეს** (არა იქნას): მიღებულ იქნეს, გათვალისწინებულ უნდა იქნეს.
- „ვიყავი / არის“-ით მიმღეობა სახელობითშია: არჩეული ვიყავი, მიღებულია.
- **სჯობს მარტივი ზმნა:** ✗ შესყიდულ იქნა → ✓ შეისყიდეს; ✗ დამტკიცებულ იქნა → ✓ დამტკიცდა; ✗ ფაილი წაშლილ იქნა მომხმარებლის მიერ → ✓ მომხმარებელმა ფაილი წაშალა. [გზ, გვ. 61; ენადეპ]
- „მიერ“-იანი ვნებითი ინგლისური passive-ის კალკია იქ, სადაც მოქმედი პირი ცნობილია; ქვემდებარედ აქციე.

## თემის ნიშნები და ფუძის ხმოვანი

- **-ამ / -ავ:** საწყისი -მა-ზე → -ამ (დასმა — სვამს, ბმა — აბამს, რტყმა — არტყამს, სხმა — ასხამს, ცმა — იცვამს, თქმა — ამბობს/უთქვამს); საწყისი -ვა-ზე → -ავ (ხატვა — ხატავს, კერვა — კერავს, მალვა — მალავს). ✗ იზავს → ✓ იზამს. [ენადეპ]
- **ხმოვანმონაცვლე ზმნები:** აწმყოში ე, წყვეტილში ი: კრეფს — მოკრიფა; გლეჯს — გაგლიჯა; ზელს — მოზილა; სრესს — გასრისა; წმენდს — გაწმინდა; გრეხს — დაგრიხა. ✗ მოკრეფა, გაგლეჯა, გაწმენდა (წყვეტილად). [ენადეპ]
- **-ევ → წყვეტილში -ია:** ანგრევს — დაანგრია; ამსხვრევს — დაამსხვრია; აბნევს — დააბნია. ✗ დაანგრივა.
- **ურჩევნია** (✗ ურჩევია); **დაანახვებს** (ვ რჩება); **შევიტყვე, შევატყვე**.
- **ეუბნება** (✗ ეუბნევა); **ადგას**, **ახურავს** (✗ ადგია, ახურია); **გაუხარდა** (✗ გაეხარდა); **იყიდდა** (✗ იყიდიდა); **იღვწის** (✗ იღწვის); **ვგავარ, ვდგავარ, ჰგავხარ** (✗ ვგევარ, ვდგევარ); **ერქვა** (✗ ქვიოდა).

## ჰ- და ს- ზმნაში: როდის იწერება და როდის არა (ნ86, გვ. 207–218)

**წესი.** ჰ-/ს- ზმნაში მხოლოდ ერთ რამეს აღნიშნავს: მესამე პირის **ირიბ ობიექტს** („მას“ — ვის? რას?, რომელიც ყველა დროში მიცემითში დგას). თუ ზმნას ასეთი „მას“ არ ახლავს, ჰ-/ს- არ იწერება.

**ტესტი.** ჰკითხე საკუთარ თავს: არის წინადადებაში (ან იგულისხმება) ადრესატი „მას/მათ“, რომელიც ნამყოშიც „მას“ რჩება? *წერილს წერს* (წერილი ნამყოში „წერილი“ ხდება: დაწერა წერილი → პირდაპირი ობიექტია → ს- არ უნდა). *მეგობარს წერილს სწერს* (მეგობარს — მისწერა მეგობარს → ირიბი ობიექტია → ს-).

**რომელი თანხმოვნის წინ რა იწერება.** ჰ- იწერება **გ, კ, ქ, ბ, პ, ფ, ყ**-ს წინ; ს- იწერება **დ, თ, ტ, ძ, ც, წ, ჯ, ჩ, ჭ**-ს წინ; ხმოვნებისა და **ვ, ზ, ლ, მ, ნ, ჟ, რ, ს, ღ, შ, ხ**-ს წინ ნიშანი არ იწერება (მატებს, რცხვენია, შია, მოხსნის, გახარებია). სუბიექტ „შენ/თქვენ“-ს ჰ-/ს- არ აღნიშნავს.

- **უნახავს / უნახია:** ექსპერტთა კომისიის 2022 წლის ნორმით -ავ/-ამ-იანი ფორმა (უნახავს, უთქვამს, დაუხატავს, წაუკითხავს) სალიტერატურო ფორმად რჩება, -ია-იანი (უნახია, უთქვია) კი დასაშვებადაა ცნობილი. წერე -ავ/-ამ-იანი ფორმა; სხვის ტექსტში -ია ფორმას შეცდომად ნუ მონიშნავ — ეს სტილის საკითხია.
