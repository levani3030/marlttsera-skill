# სტილი: კალკები, კანცელარიზმები, პარონიმები

წყარო: „ოფიციალურ-საქმიანი დოკუმენტების მართლწერის გზამკვლევი“ (2024), თავი III; Microsoft-ის ქართული სტილის გზამკვლევი. გვერდები მითითებულია PDF-ის მიხედვით.

## სარჩევი
1. მთავარი პრინციპი: მოქმედება ზმნით გამოხატე

## 1. მთავარი პრინციპი: მოქმედება ზმნით გამოხატე

ქართულისთვის ბუნებრივია მარტივი ზმნა. „დამხმარე ზმნა + სახელზმნა“ (ახდენს გადახდას, მოხდა შეფასება, ახორციელებს შესყიდვას) ხელოვნური, კანცელარიული წყობაა და ტექსტს ამძიმებს. თუ კონსტრუქციის ზმნას საკუთარი შინაარსი აღარ აქვს და მხოლოდ სახელზმნას „ატარებს“, ჩაანაცვლე სახელზმნისგან ნაწარმოები ზმნით. (გვ. 95–101)

შემოწმება: ამოიღე დამხმარე ზმნა და სახელზმნა ზმნად აქციე. თუ აზრი არ შეიცვალა — მარტივი ზმნა სჯობს.

- ✗ დამსაქმებელი ახდენს გადასახადების გადახდას → ✓ დამსაქმებელი იხდის გადასახადებს
- ✗ შესაძლებელია მოხდეს ხელშეკრულების შეწყვეტა → ✓ შესაძლებელია, ხელშეკრულება შეწყდეს
- ✗ რესპონდენტის მიერ მოხდა პროტესტის წარდგენა → ✓ რესპონდენტმა პროტესტი წარადგინა
- ✗ ვალდებულია განახორციელოს ინვენტარის შესყიდვა → ✓ ვალდებულია, შეისყიდოს ინვენტარი

## 4. ქონა-ყოლის ზმნები: აქვს / გააჩნია

„გააჩნია“, „მოეპოვება“, „აბადია“, „მოეძევება“ უქონლობას გამოხატავს: იხმარება უარყოფით („არ გააჩნია“) და კითხვით („რა გააჩნია?“) კონტექსტში. დადებითი შინაარსისთვის — **აქვს**, **ჰყავს**. (გვ. 108–109)

- ✗ მონაცემებს იურიდიული მნიშვნელობა გააჩნია → ✓ მონაცემებს იურიდიული მნიშვნელობა აქვს
- ✗ კომპანიას მოეპოვება შესაბამისი რესურსი → ✓ კომპანიას აქვს შესაბამისი რესურსი
- ✓ სარჩელს სამართლებრივი საფუძველი არ გააჩნია

(სხვა ზმნაა „გააჩნია“ = „დამოკიდებულია“: გააჩნია, ვინ იკითხავს.)

## 5. ტავტოლოგია

ერთ წინადადებაში ერთი ფუძის ზმნა და სახელზმნა (ან ორი ერთფუძიანი სიტყვა) ერთად ნუ მოხვდება; ერთ-ერთი სინონიმით შეცვალე ან წინადადება გაამარტივე. (გვ. 105–107)

- ✗ კისრულობს ვალდებულებას, შეასრულოს მისთვის დაკისრებული სამუშაო → ✓ ვალდებულებას იღებს, შეასრულოს მისთვის დაკისრებული სამუშაო
- ✗ განსახორციელებელი მოქმედებების განხორციელებაზე → ✓ განსახორციელებელი მოქმედებების შესრულებაზე
- ✗ გაფორმებული ხელშეკრულების შესაბამისად ვაფორმებთ აქტს → ✓ დადებული ხელშეკრულების შესაბამისად ვაფორმებთ აქტს

## 7. ინგლისურიდან თარგმნისას და ინგლისურად „ნაფიქრი“ ტექსტის წერისას

(Microsoft-ის ქართული სტილის გზამკვლევი, §2.1, §4.1)

- **პირის ნაცვალსახელი ზედმეტია**, თუ პირს ზმნა უკვე გამოხატავს: ✗ თქვენ გსურთ, დაამატოთ → ✓ გსურთ, დაამატოთ. ნაცვალსახელის გამეორება წინადადებას არაქართულ ჟღერადობას აძლევს.
- **კუთვნილებითი ნაცვალსახელი** ქართულში გაცილებით იშვიათია: ✗ დაგავიწყდათ თქვენი პაროლი? → ✓ დაგავიწყდათ პაროლი? ✗ გამოიყენეთ თქვენი მაუსი → ✓ გამოიყენეთ მაუსი.
- **they/their ერთი პირის მნიშვნელობით** → ის, მისი (არა „ისინი“, „მათი“).
- **სიტყვასიტყვით ნუ თარგმნი** იდიომებსა და მეტაფორებს: გადმოეცი აზრი; თუ იდიომი აზრს არაფერს მატებს — გამოტოვე.
- **მარტივი, სასაუბრო სიტყვა** სჯობს ოფიციალურს: „მეტია“ („აღემატება“-ს ნაცვლად), „ასევე“ („დამატებით“-ის ნაცვლად), „საშუალება გაქვთ“ („შანსი გაქვთ“-ის ნაცვლად). ეს არჩევანია ახალი ტექსტის წერისას და არა შეცდომა სხვის ტექსტში.
- **მარტივი დრო**: აწმყო და წყვეტილი; მყოფადი — მხოლოდ მაშინ, როცა რამე მართლა მომავალში მოხდება.
- **კავშირიანი მოკლე წინადადება** სჯობს სახელზმნურ ჯაჭვს: ✗ მეტი საკვანძო სიტყვის მითითების შემთხვევაში სტატიის ხილვადობა გაუმჯობესდება → ✓ თუ მეტ საკვანძო სიტყვას გამოიყენებთ, სტატია უფრო ადვილად მოიძებნება.
- **თანდებული ქართულში სიტყვას ერთვის**: ინგლისური წინდებულის გამოტოვება ან წყობის გადმოტანა შეცდომაა (connect to the device → მოწყობილობასთან დაკავშირება).
- **სრულ წინადადებას ზმნა სჭირდება**: „მოხდა უცნობი შეცდომა.“ (სათაურად/ჭდედ ზმნის გარეშეც შეიძლება: „უცნობი შეცდომა“).

## 8. წინადადების აგება

- ორი მართებული წყობიდან აირჩიე უფრო მარტივი და მოქნილი. (გვ. 148)
- ზერთული (მრავალსაფეხურიანი) წინადადება დაშალე რამდენიმე წინადადებად: გრძელ კონსტრუქციაში აზრი ბუნდოვანდება და შეთანხმების შეცდომები ჩნდება. (გვ. 149)
- ნათესაობითების გრძელი ჯაჭვი („სამინისტროს სისტემის თანამშრომელთა კვალიფიკაციის ამაღლების ხელშეწყობის მიზნით“) დაშალე ზმნით ან დამოკიდებული წინადადებით.
- სიტყვა გამოიყენე პირდაპირი მნიშვნელობით; ერთი ცნება ერთ ტექსტში ერთი ტერმინით აღნიშნე.
