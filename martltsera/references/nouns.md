# სახელები: ბრუნება, თანდებულები, ნაცვალსახელები

წყაროები: „თანამედროვე ქართული სალიტერატურო ენის ნორმები, I კრებული“ (1986) [ნ86, გვერდები PDF-ის მიხედვით]; მთავრობის №394 (2020) და №362 (2025) დადგენილებებით დამტკიცებული ნორმები და სახელმწიფო ენის დეპარტამენტის შესწორებათა ბაზა [ენადეპ]; „ოფიციალურ-საქმიანი დოკუმენტების მართლწერის გზამკვლევი“ (2024) [გზ].

- სახელი და გვარი; წოდება + სახელი; ბატონი / ქალბატონი
- ვითარებითი ბრუნვა: -დ / -ად
- წოდებითი (მიმართვის) ფორმა
- ადამიანის სახელების ბრუნება
- ვინმე, რამე, იგივე, ვიღაც, რაღაც

## ფუძის კუმშვა და კვეცა

მექანიკურად „ფუძე + ნიშანი“ არ იწებება: ნათესაობითში, მოქმედებითსა და ვითარებითში, ასევე -ებ-იან მრავლობითში ბევრი ფუძე იკუმშება ან იკვეცება. ეს ენობრივი მოდელების ტიპური შეცდომაა.

- **კუმშვა** (ფუძის ბოლო მარცვლის ხმოვანი ვარდება): მეგობარი — მეგობრის, მეგობრები; სოფელი — სოფლის, სოფლები; მომხმარებელი — მომხმარებლის, მომხმარებლები, მომხმარებლისთვის; წელი — წლის; ნომერი — ნომრის; ფანჯარა — ფანჯრის, ფანჯრები; ქვეყანა — ქვეყნის, ქვეყნები. ნასესხები სიტყვა ხშირად არ იკუმშება: ფაილი — ფაილის, მოდელი — მოდელის, სერვერი — სერვერის, კაბელი — კაბელის, პაროლი — პაროლის.
- **კვეცა** (ბოლოკიდური ა ან ე ვარდება ნათესაობითსა და მოქმედებითში): პროგრამა — პროგრამის, პროგრამით; სისტემა — სისტემის; ბაზა — ბაზის; მთა — მთის; მოსწავლე — მოსწავლის; ხე — ხის. მიცემითში ფუძე სრულია: პროგრამას, სისტემას. ა-ფუძიანი -ებ-ის წინაც იკვეცება (პროგრამები, სისტემები, ბაზები), ე-ფუძიანი — არა (მოსწავლეები, ხეები). ადამიანის სახელი არ იკვეცება: ილიას, ანას, ელენეს. ო- და უ-ფუძიანი არ იკვეცება: მენიუ — მენიუს, მენიუთი; რადიო — რადიოს; ეზო — ეზოს.
- ✗ ფანჯარის, მეგობარის, პროგრამაის, მომხმარებელთვის → ✓ ფანჯრის, მეგობრის, პროგრამის, მომხმარებლისთვის.
- ტოპონიმები ჩვეულებრივ იკვეცება: აჭარის, გაგრის, ბარსელონის (✗ აჭარას წარმომადგენელი).
- კნინობითი -ა/-ია და უცხოური ე-, ი-ფუძიანი სახელები უკვეცელია: დათუნიას, კაფეს, ატელიეს, ტურნეს; ვისკის, ტაქსის, ჰობის.
- საეჭვო ფორმა შეამოწმე: სიტყვა ხმამაღლა „წაიკითხე“ ნათესაობითში; თუ არაბუნებრივად ჟღერს, ფუძე არასწორადაა აგებული.

## სახელი და გვარი; წოდება + სახელი; ბატონი / ქალბატონი

- **სახელი + გვარი:** იბრუნვის მხოლოდ გვარი, სახელი ფუძის სახითაა: ილია ჭავჭავაძემ, ნიკოლოზ ბარათაშვილს, დავით აღმაშენებლის, თამარ მეფის. ✗ დიპლომი მიეცა დავითი აბესაძეს → ✓ დავით აბესაძეს. [№362, დანართი 7]
- **გვარი + სახელი** (სიებში): ბარათაშვილი ნიკოლოზი; მიცემითში — ბარათაშვილ ნიკოლოზს.
- არაქართულ გვარსაც სახელობითში -ი ერთვის: პეტროსიანი, სმითი (✗ პეტროსიან).
- **წოდება / თანამდებობა / პროფესია + სახელი და გვარი:** თანხმოვანფუძიანი მსაზღვრელი ნიშანს იღებს მხოლოდ სახელობითში, მოთხრობითსა და წოდებითში; დანარჩენ ბრუნვებში ფუძის სახითაა. ხმოვანფუძიანი (მოსამართლე, მოადგილე) არ იცვლება. [გზ, გვ. 74–75; №362]

|---|---|---|
| სახ. | პროფესორი ნინო რაზმაძე | მოსამართლე ნუგზარ ბახტაძე |
| მოთხრ. | პროფესორმა ნინო რაზმაძემ | მოსამართლე ნუგზარ ბახტაძემ |
| მიც. | პროფესორ ნინო რაზმაძეს | მოსამართლე ნუგზარ ბახტაძეს |
| ნათ. | პროფესორ ნინო რაზმაძის | მოსამართლე ნუგზარ ბახტაძის |
| მოქმ. | პროფესორ ნინო რაზმაძით | მოსამართლე ნუგზარ ბახტაძით |

- **ბატონი / ქალბატონი + სახელი:** სახ. ბატონი ზურაბი; მოთხრ. ბატონმა ზურაბმა; მიც. ბატონ ზურაბს; ნათ. ბატონი ზურაბის; მოქმ. ბატონი ზურაბით; წოდ. ბატონო ზურაბ. ✗ ბატონ ლევანის ლექცია → ✓ ბატონი ლევანის ლექცია. [№362; ენადეპ] (პრაქტიკაში, გზამკვლევშიც, გვხვდება „ქალბატონ ნინო გვანცელაძის“ — სახელისა და გვარის წინ ფუძის სახით.)
- წერილში მიმართვა: „ბატონო დავით,“ / „ქალბატონო ნინო,“ / „პატივცემულო ბატონო გიორგი,“.

## ვითარებითი (მიმართულებითი) ბრუნვა: -დ / -ად
კითხვებზე „როგორ? რად? რამდენად?“ სახელი -დ/-ად-ზე ბოლოვდება და არა -თ/-ათ-ზე. თ-თი იწერება მხოლოდ ზმნისართები: გარეთ, ზემოთ, ქვემოთ, წინათ, უკეთ, ალბათ, უნებლიეთ (როგორც ზევით, ქვევით, შიგნით).
სწორია: კარგად, დიდად, მაგრად, კაცად, ამხანაგად, სოფლად, სამად, ხედ
არასწორია: კარგათ, დიდათ, მაგრათ, კაცათ; ალბად, უკედ (გვ. 77)

## წოდებითი (მიმართვის) ფორმა
- თანხმოვანფუძიანი საზოგადო სახელი და გვარი: -ო — კაცო, მეგობარო, ამხანაგო; წერეთელო, ბარათაშვილო, ივანოვო; თბილისო, მტკვარო.
- ხმოვანფუძიანი მრავალმარცვლიანი: -ვ ან უცვლელად — დედავ / დედა, ქვეყანავ / ქვეყანა, სამშობლოვ / სამშობლო; ერთმარცვლიანი: -ო — ძმაო, დაო, მზეო (ლექსში: ძმავ, მზევ).
- ადამიანის სახელი — დაბოლოების გარეშე: გურამ, ნოდარ, თენგიზ, ეთერ, დავით, ვახტანგ; ხმოვანფუძიანები უცვლელად: ლუკა, პეტრე, ელენე, გიორგი, აკაკი, მერი.
- -ძე, -ვა, -უა, -ია გვარები და ი-ფუძიანი უცხო გვარები — უცვლელად: ჭავჭავაძე, ნოდია, გორკი, ტოლსტოი.
- ტიტულები: გრაფო, ლორდო, ჰერცოგო; უცვლელია: მადამ, მისტერ, მის, მისის, სერ, ლედი.
არასწორია: გურამი! ნოდარი! თენგიზი! (მიმართვისას); დარეჯანო, პეტრევ (დიალექტური) (გვ. 78–80)

## ადამიანის სახელების ბრუნება
თანხმოვანფუძიან სახელებში -ი მხოლოდ სახელობითის ნიშანია: მოთხრობითში -მა, მიცემითში -ს, მიმართვისას ფუძე. ი-ფუძიან სახელებში -ი ყველგან რჩება (-მ, -ს). ტესტი: თუ სახელს ი-ს გარეშე ვერ იტყვი (გიორგ-?), ი ფუძისაა.
სწორია: გურამმა, გურამს, გურამ!; ნოდარმა, თამარმა, ვახტანგმა, ოთარს, ეთერმა, უშანგმა; გიორგიმ, გიორგის, გიორგი!; აკაკიმ, ირაკლიმ, გივიმ, დიმიტრის, მერიმ, ლალის
არასწორია: გურამიმ, ნოდარიმ, თამარიმ, ოთარიმ, ეთერიმ; ნოდარის (მიცემითად); გურამი! (მიმართვისას)
ი-ფუძიანები (ნიმუშები): აკაკი, ალექსი, გიორგი, გივი, დიმიტრი, ირაკლი, ევგენი, ლავრენტი, სერგი, ბადრი, გოდერძი, დაჩი; ლალი, ლილი, მერი, ნანული, დალი.
- სიაში გვარის შემდეგ სახელი 1986 წლის ნორმით ფუძის სახით იწერებოდა (აბაშიძე მიხეილ); 2025 წლის ნორმით (№362) სახელიც იბრუნვის: ბარათაშვილი ნიკოლოზი, ბარათაშვილ ნიკოლოზს.
- ი-ზე დაბოლოებული უცხო სახელები: დელიში, ტრიპოლიმდე (არა დელში, ტრიპოლში); მრავლობითში ი იკარგვის: ტოლსტოები, ტრამვაები.
(გვ. 91–102)

## ვინმე, რამე, იგივე, ვიღაც, რაღაც — ბრუნება
ნაწილაკიანი ნაცვალსახელი ბრუნვის ნიშანს ბოლოში ირთავს (ვინმე-მ, რამე-ს). „იგივე“ და „ერთი და იგივე“ მხოლოდ სახელობითშია; სხვა ბრუნვებში ფუძე იცვლება: იმავე, ერთსა და იმავე. მრავლობითი: ვიღაცები, რაღაცები (არა -ეები).

| | ვინმე | რამე | იგივე | ერთი და იგივე |
|---|---|---|---|---|
| მოთხრ. | ვინმემ | რამემ | იმანვე / მანვე | ერთმა და იმავემ |
| მიც. | ვინმეს | რამეს | იმასვე / მასვე | ერთსა (ერთ) და იმავეს |
| ნათ. | ვინმეს(ი) | რამის / რამეს(ი) | იმისვე / მისვე | ერთისა (ერთი) და იმავეს(ი) |
| მოქმ. | ვინმეთი | რამით / რამეთი | იმითვე / მითვე | ერთითა (ერთი) და იმავეთი |

მსაზღვრელად: ვინმე, რამე (დასაშვებია რაიმე), რამდენიმე, რომელიმე, ორივე, ვიღაც(ა), რაღაც(ა) უცვლელია (რამდენიმე სიტყვის, ორივე სკოლას); იგივე → იმავე.
სწორია: იმავე წიგნს, იმავე კაცმა, ერთსა და იმავე წიგნს, ერთმა და იმავე კაცმა, რამეს, რაღაცის, რაღაცით, ვიღაცებს, რაღაცები, ორივე სკოლის
არასწორია: იგივე წიგნს, იგივე კაცმა, ერთი და იგივე წიგნს, ერთი და იგივე კაცმა, იგივემ, იგივეს, რასმეს, რიღაცის, რიღაცით, ვიღაცეებს, რაღაცეები, ორთავე სკოლის
(გვ. 106–110)

## თანდებულები: -ზე, -ში, -თან, -მდე, -გან, -ვით, -თვის, -კენ
- მხოლოდ **-ზე** (არა -ზედ): თავზე, ხელზე, მაგიდაზე. ნაწილაკებთან ორივე მართებულია: მთაზეც // მთაზედაც; მთაზევე // მთაზედვე.
- **-ში**; -ც-სთან: ამაშიც (ასევე შეიძლება ამაშიაც).
- **-თან**: თანხმოვანფუძიანთან უ-ს-ოდ (სახლთან), ხმოვანფუძიანთან -ს-ით (მამასთან, ეზოსთან). უპირატესია: დედასთანაც, დედასთანვე; მაგრამ: ამასთანავე.
- **-მდე** ძირითადია; -მდის დასაშვებია (ნახვამდის, ხვალამდის — მყარი ფორმებია). -მდი, -მდინ არ შეიძლება.
- **-გან**: ვისგან? რისგან? (წყარო, მასალა, მიზეზი) → ნათესაობითი + -გან: ამხანაგისგან, ჭარხლისგან. საიდან? როდიდან? → -იდან/-დან: ქალაქიდან, დილიდან, წყაროდან. არ აურიოთ.
- **-ვით**: ხმოვანფუძიანთან მხოლოდ -სავით (მზესავით, კატასავით); თანხმოვანფუძიანთან უპირატესია -სავით (კაცსავით), დასაშვებია -ივით (კაცივით). ნაცვალსახელი: ჩემსავით. ჩვენებითი: ამ კაცივით.
- -თვის, -კენ, -გან: ორივე სწორია — ძმისთვის/ძმისათვის, სახლისკენ/სახლისაკენ; ოდნავ უპირატესია მოკლე.
სწორია: თავზე, ხელზე, მიწაზედვე, აქამდე, ქალაქიდან, უნივერსიტეტისგან (მიწვევა), ჩემსავით, თქვენსავით, ამ კაცივით, ძმისაგანაც, ძმისაგანვე
არასწორია: თავზედ, ხელზედ, მიწაზევე, აქამდი, აქამდინ, ქალაქიდგან, ქალაქიდამ, უნივერსიტეტიდან (მიწვევა), ჩემივით, თქვენივით, ეს კაცივით
(გვ. 111–120)

შენიშვნები მოქმედი ნორმების მიხედვით [№394, 2020; №362, 2025]:
- „რაიმე“ დასაშვებია მსაზღვრელადაც (რაიმე საკითხი) და ცალკეც (რაიმეს იტყვის); სახელობითში მართებულია „რამ“-იც (ბევრი რამ მოხდა).
- -ც ნაწილაკთან ორივე მართებულია: მთაზეც // მთაზედაც, მთაშიც // მთაშიაც; -ვე-სთან: მთაზევე // მთაზედვე.
- ამანვე, იმასვე // ამავემ, იმავეს — ორივე მართებულია.
- „უნებლიედ“ მართებულია (უნებლიედ შეცდა); „უნებლიეთ“ — გამოთქმაში „ნებსით თუ უნებლიეთ“.
