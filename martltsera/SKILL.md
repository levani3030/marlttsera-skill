# მართლწერა

ეს სკილი იმისთვისაა, რომ ქართულად დაწერილი ტექსტი იყოს გამართული: სწორი ბრუნვებით, შეთანხმებით, მართლწერით, პუნქტუაციითა და ბუნებრივი, არანათარგმნი წყობით. წესები ამოკრებილია ქართული სალიტერატურო ენის ოფიციალური ნორმებიდან (იხ. `references/sources.md`).

მოქმედებს ყოველთვის, როცა ქართულად წერ — ერთ წინადადებაზეც. მოკლე პასუხში შეცდომა ისევე თვალშისაცემია, როგორც ვრცელ დოკუმენტში.

## როგორ იმუშაო

**1. იფიქრე ქართულად.** წინადადება თავიდანვე ქართულად ააგე და ინგლისურიდან ნუ თარგმნი: შეცდომების უმეტესობა (ზედმეტი ნაცვალსახელი, ვნებითი „მიერ“-ით, სახელზმნების ჯაჭვი, არასწორი ბრუნვა) ინგლისური წყობის გადმოტანით ჩნდება.

**2. წერისას დაიცავი ქვემოთ მოცემული ძირითადი წესები** („ყველაზე ხშირი შეცდომები“). თუ კონკრეტულ ფორმაში დარწმუნებული არ ხარ:
- ნახე შესაბამისი ფაილი `references/`-ში (რუკა ქვემოთ);
- რთული სიტყვა (ერთად / დეფისით / ცალკე) ან საეჭვო ფორმა მოძებნე: `node "<სკილის საქაღალდე>/scripts/lookup.mjs" სიტყვა`;
- თუ მაინც ვერ დაადგინე, აირჩიე სხვა, უეჭველი სიტყვა ან მარტივი კონსტრუქცია. სიტყვას ნუ გამოიგონებ და ფორმას მექანიკურად (ფუძე + ნიშანი) ნუ ააწყობ.

**3. გაგზავნამდე გადაიკითხე ტექსტი თვითშემოწმების სიით** (ქვემოთ). ეს ნაბიჯი სავალდებულოა; სწორედ აქ იჭერ იმას, რაც წერისას გაგეპარა.

**4. ფაილში ჩაწერილი ქართული ტექსტი გაატარე შემმოწმებელში:**

```
node "<სკილის საქაღალდე>/scripts/lint.mjs" <ფაილი> [<ფაილი>...]
node "<სკილის საქაღალდე>/scripts/lint.mjs" --text "ტექსტი"
```

„სკილის საქაღალდე“ არის ამ სკილის ჩატვირთვისას ნაჩვენები Base directory (ჩვეულებრივ `~/.claude/skills/martltsera`). შემმოწმებელი იჭერს მხოლოდ მექანიკურ შეცდომებს: ნორმით უარყოფილ ფორმებს, შერეულ დამწერლობას, ბრჭყალებს, ჰარებს, აშკარა მძიმეებს. `error` თითქმის ყოველთვის ნამდვილი შეცდომაა; `warn` და `info` მინიშნებაა — კონტექსტში გადაამოწმე და ბრმად ნუ შეცვლი. გრამატიკასა და სტილს ის ვერ ამოწმებს; ეს შენი საქმეა.

**5. მომხმარებლის ნება და პროექტის წესი უპირატესია.** თუ მომხმარებელს ან პროექტს დამკვიდრებული ტერმინი, სტილი ან დაწერილობა აქვს, მას მიჰყევი. სხვისი ტექსტის ჩასწორებისას შეინარჩუნე ავტორის ხმა: გაასწორე შეცდომა და არა სტილი.

სკილის გამოყენებაზე მომხმარებელს ნუ მოუყვები; უბრალოდ დაწერე გამართულად.

## ყველაზე ხშირი შეცდომები

ქვემოთ ის წესებია, რომლებსაც ენობრივი მოდელი ყველაზე ხშირად არღვევს. ✗ — არასწორი, ✓ — სწორი.

### ბრუნვა და ზმნა

ქვემდებარის ბრუნვას ზმნის დრო განსაზღვრავს (გარდამავალი ზმნისთვის):

| დრო | ქვემდებარე | პირდაპირი დამატება | მაგალითი |
|---|---|---|---|
| აწმყო, მყოფადი, უწყვეტელი | -ი | -ს | მომხმარებელი ხსნის ფაილს |
| წყვეტილი; II კავშირებითი (უნდა გახსნას, რათა გახსნას) | -მა | -ი | მომხმარებელმა გახსნა ფაილი; მომხმარებელმა უნდა გახსნას ფაილი |
| თურმეობითი („გაუხსნია“, „არ გაუხსნია“) | -ს | -ი | მომხმარებელს ფაილი არ გაუხსნია |

- ✗ მომხმარებელი დააჭირა ღილაკს → ✓ მომხმარებელმა დააჭირა ღილაკს
- ✗ სისტემამ ფაილს წაშალა → ✓ სისტემამ ფაილი წაშალა
- ვნებით და მოძრაობის ზმნასთან (იხსნება, წაიშალა, მოვიდა, შევიდა) ქვემდებარე ყოველთვის -ი: ✓ ფაილი წაიშალა; მომხმარებელი უნდა შევიდეს სისტემაში. ✗ ფაილმა წაიშალა. საშუალ ზმნასთან (მუშაობს, ფიქრობს, თამაშობს) წყვეტილში -მა: ✓ პროგრამამ იმუშავა.
- აქვს, ჰყავს, სჭირდება, მოსწონს, უნდა, შეუძლია: „ვის?“ მიცემითში: ✓ მომხმარებელს სჭირდება პაროლი. უსულო — აქვს, სულიერი — ჰყავს.
- **უნდა / შეიძლება / რათა / მინდა, რომ** + კავშირებითი: ✓ უნდა გააკეთოს; მინდა, რომ მოვიდეს. ✗ უნდა გააკეთებს. („რომ“ თავისთავად კავშირებითს არ ითხოვს: ვიცი, რომ მოვა.) ბრუნვას ზმნის ფორმა განსაზღვრავს და არა სიტყვა „უნდა“.
- შეუძლებლობა — „ვერ“: ✓ ფაილი ვერ გაიხსნა. ✗ არ შეძლო გახსნა.
- ფუძე იკუმშება / იკვეცება: ფანჯრის, მეგობრის, მომხმარებლის, პროგრამის, წლის. ✗ ფანჯარის, მომხმარებელის, პროგრამაის.

### შეთანხმება

- **რაოდენობის სიტყვის შემდეგ არსებითი მხოლობითშია:** სამი ფაილი, ბევრი ადამიანი, რამდენიმე შეცდომა, ყველა მომხმარებელი, თითოეული მონაწილე, სხვადასხვა ქვეყანა. ✗ სამი ფაილები, ყველა მომხმარებლები, სხვადასხვა ქვეყნები.
- **უსულო მრავლობით ქვემდებარესთან ზმნა მხოლობითშია:** ფაილები წაიშალა; ცვლილებები შევიდა ძალაში. ✗ ფაილები წაიშალნენ. სულიერთან — მრავლობითი: მომხმარებლები ხედავენ.
- ✓ ვალდებული არიან, უფლებამოსილი არიან. ✗ ვალდებულნი არიან.
- **რომელიც** რიცხვში ეთანხმება: საკითხები, რომლებიც…; არსებითი სახელის ასახსნელად „რომელიც“ და არა „რაც“: ✓ დოკუმენტი, რომლის მიხედვითაც…
- მსაზღვრელი მიცემითში ფუძის სახითაა, ნათესაობითში -ი: ✓ ახალ ფაილში, ახალი ფაილის. ✗ ახალი ფაილში.

### ნაცვალსახელი და თანდებული

- **იგივე** მხოლოდ სახელობითშია; სხვაგან **იმავე**: ✓ იმავე პრობლემაზე; ერთსა და იმავე დროს. ✗ იგივე პრობლემაზე.
- მე / შენ / ჩვენ / თქვენ + ცალკე მდგომი თანდებული — უ-ს-ოდ: ✓ ჩემ მიერ, თქვენ მიერ, ჩვენ შორის, ჩემ გამო. ✗ ჩემს მიერ, თქვენს მიერ.
- კუთვნილებითი ნაცვალსახელი არსებითთან მიცემითში — -ს-ით: ✓ თქვენს ანგარიშზე, ჩვენს წერილს. ✗ თქვენ ანგარიშზე.
- ✓ ერთი მხრივ, მეორე მხრივ. ✗ ერთის მხრივ.
- ერთი თანდებული (-ზე, -ში, -თან, -თვის, -გან) „და“-თი შეერთებულ ორ სახელზე: ✓ გზებსა და ხიდებზე; ტელევიზიასა და რადიოში. ✗ გზებზე და ხიდებზე.
- ✓ 2024 წელს, გასულ წელს. ✗ 2024 წელში. ✓ ორი წლის წინ. ✗ ორი წლის უკან.
- -გან (ვისგან? რისგან?) / -დან (საიდან? როდიდან?): ✓ წერილი მივიღე კოლეგისგან; ქალაქიდან ჩამოვიდა.
- სახელი + გვარი: იბრუნვის მხოლოდ გვარი: ✓ ნინო ბერიძემ, დავით აბესაძეს. თანამდებობა გვარის წინ: ✓ დირექტორ გიორგაძის ბრძანებით. მიმართვა: ✓ ბატონო დავით, ქალბატონო ნინო. თანხმოვანფუძიანი სახელი: ✓ ნოდარმა, თამარმა (✗ ნოდარიმ); ი-ფუძიანი: გიორგიმ.

### ზმნის ფორმა

- **ჰ- / ს-** იწერება, როცა ზმნას აქვს მესამე პირის ირიბი ობიექტი („მას“): ✓ ჰყავს, ჰქონდა, ჰქვია, ჰგავს, ჰგონია, ჰკითხა; სჭირდება, სჯერა, მოსწონს, მისცა, შესთავაზა, მოსთხოვა. ✗ ყავს, ქონდა, ჭირდება, მოწონს, შეთავაზა.
- …და არ იწერება, როცა ასეთი ობიექტი არ არის: ✓ თქვა, ჩანს, წარდგა, შედგა, ცხადყოფს. ✗ სთქვა, სჩანს, წარსდგა, ცხადჰყოფს.
- ✓ ახორციელებს, ავითარებს, ათავისუფლებს, ასხვავებს (ან: განახორციელებს). ✗ ანხორციელებს, ანვითარებს, ანთავისუფლებს.

## თვითშემოწმება გაგზავნამდე
